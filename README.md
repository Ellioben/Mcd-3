## 🎯 产品是什么

麦门点餐派是一个**麦当劳智能配餐工具**。用户输入想吃的口味、人数、忌口，系统立刻给出**三派套餐**：

| 派别 | 主张 | 核心指标 | 适合人群 |
|:---:|:---|:---|:---|
| 🔴 **满足派** | 吃得够爽才叫吃饭 | 满足感提升幅度 | 饿了、想犒劳自己 |
| 🟡 **省钱派** | 同样吃饱，花得更少 | 比最贵一单省多少钱 | 精打细算、学生党 |
| 🟢 **低卡派** | 控制热量，不亏待嘴 | 比最热一单少多少大卡 | 健身、减脂期 |

不是简单排序，是**配餐**——主品 / 小食 / 饮料 / 加餐各槽位联动，保证是一顿完整的饭。

## 📱 产品形态规划

### 形态一：独立网站（当前形态）

> 已上线：[ellioben.github.io/Mcd-3](https://ellioben.github.io/Mcd-3/)

- **定位**：轻量化体验入口，传播成本最低
- **价值场景**
  - 小红书 / 朋友圈分享：「来测测你的麦当劳本命套餐」
  - 社媒引流：点进去直接玩，不用下载不用关注
  - 产品验证：快速迭代功能，验证用户留存和分享率
- **优势**：零成本部署、跨平台、即点即用
- **下一步**：接入更多门店数据、增加分享海报生成

### 形态二：微信小程序

> 规划中

- **定位**：主力产品形态，深度服务日常决策
- **价值场景**
  - **到店前**：地铁上选好套餐，到店直接点，减少决策时间
  - **排队时**：犹豫吃什么？三派对比一下就有答案
  - **社交裂变**：「帮我看看今天吃哪派？」一键分享给朋友选
  - **会员打通**：对接麦当劳会员，自动识别已有优惠券和积分
- **关键功能规划**
  - 定位自动匹配最近门店
  - 历史点餐记录 + 偏好学习
  - 生成取餐码 / 跳转到麦当劳小程序下单
  - 好友拼单：多人忌口合并出最优解
- **为什么值得做**：点餐是高频刚需，小程序天然适合「即用即走」的决策场景

### 形态三：线下点餐机

> 概念阶段

- **定位**：门店内的智能推荐屏，降低选择困难
- **价值场景**
  - **高峰期**：顾客在排队时已经选好，到柜台直接说「来省钱派双人餐」，点单效率翻倍
  - **新客转化**：第一次来麦当劳不知道点什么？三派方案帮你快速决策
  - **客单价提升**：满足派天然推荐更丰富的搭配，带动加购
  - **健康诉求**：低卡派满足越来越多的健康饮食需求
- **落地形态**
  - 门店自助点餐机内置「三派推荐」入口
  - 门店门口的互动屏：扫码选择忌口，手机上看详细方案
  - 取餐区电子屏：每日推荐三派套餐，制造话题感

## ✨ 核心卖点

### 对用户
- **决策减负**：不用在 100+ 商品里翻，三选一就够了
- **懂你的矛盾**：既想省钱又怕饿？既要好吃又怕胖？三派摆出来，自己挑
- **真实可信**：数据全来自麦当劳真实接口，价格、库存、营养都是实的
- **越用越准**：记录你的偏好，下次推荐更对味

### 对麦当劳
- **提升客单价**：满足派引导加购，平均单额上涨
- **降低决策时间**：排队更快，翻台率更高
- **健康品牌形象**：低卡派传递「麦当劳也能健康吃」的认知
- **数据洞察**：了解不同城市、时段的用户偏好分布
